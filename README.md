# my-cardgame

シャドウバースのルールをベースにした、スマートフォン向けの1人用カードゲームです。  
プレイヤーはカードを場に出し、フォロワーで相手のカードやリーダーを攻撃して、相手リーダーのHPを0にすることを目指します。

## どんなゲーム？

自分とCPUが交互にターンを進めるカードゲームです。

- 自分とCPUには、それぞれリーダーがいます
- リーダーのHPは20から始まります
- カードを場に出すにはPPを使います
- 場に出したフォロワーで、相手のフォロワーやリーダーを攻撃できます
- 相手リーダーのHPを0にしたら勝ちです
- 自分のリーダーHPが0になると負けです
- ターン開始時にデッキからカードを引けない場合も負けになります

## 画面の見方

画面は大きく分けて、CPU側、自分側、メッセージエリアで構成されています。

### CPU側

画面の上側に表示されます。

- CPUのHP
- CPUのPP
- CPUの手札枚数
- CPUの場のカード
- CPUのデッキ枚数
- CPUの墓地枚数

CPUの手札は、カードの中身が見えないように表示されます。

### 自分側

画面の下側に表示されます。

- 自分のHP
- 自分のPP
- 自分の手札
- 自分の場のカード
- 自分のデッキ枚数
- 自分の墓地枚数

自分の手札は中身を見ることができます。

### メッセージエリア

画面中央付近に、現在できる操作やメッセージが表示されます。  
カードを選択すると、「場に出す」「バトル」「リーダーを直接攻撃」「キャンセル」などのボタンが表示されます。

## 基本ルール

### HP

リーダーの体力です。  
最初は自分もCPUも20です。

相手の攻撃によってHPが減ります。  
HPが0になると負けです。

### PP

カードを出すために使うポイントです。  
ターンが進むごとに使えるPPの上限が増えていきます。

- ターン開始時に最大PPが1増えます
- PPはターン開始時に全回復します
- PPの最大値は10です
- カードを場に出すと、そのカードのコスト分だけPPを使います

例：  
現在PPが3あるとき、コスト2のカードを出すと、残りPPは1になります。

### 手札

手札は、自分が使えるカードです。  
ゲーム開始時に4枚引きます。  
その後、自分のターン開始時に1枚引きます。

### デッキ

カードを引く山札です。  
ターン開始時にデッキからカードを引きます。  
カードを引こうとしたときにデッキが空だった場合、その時点で負けになります。

### 場

カードを出す場所です。  
現時点では、自分もCPUも場に出せるカードは最大3枚です。

### 墓地

倒されたカードが置かれる場所です。

## カードの見方

カードには主に以下の情報があります。

- コスト：場に出すために必要なPP
- 攻撃力：攻撃したときに相手へ与えるダメージ
- 体力：カード自身のHP

カードの「詳細」ボタンを押すと、カードの情報を大きく確認できます。

## 遊び方

### 1. 手札からカードを場に出す

自分の手札にあるカードをクリックまたはタップします。  
メッセージエリアに「場に出す」ボタンが表示されたら、それを押します。

ただし、以下の場合はカードを出せません。

- PPが足りない場合
- 自分の場がすでに3枚で埋まっている場合
- 自分のターンではない場合

### 2. 場のカードで攻撃する

自分の場にあるカードをクリックまたはタップします。  
メッセージエリアに操作ボタンが表示されます。

攻撃方法は2種類あります。

#### 相手のカードを攻撃する

1. 自分の場のカードを選ぶ
2. 「バトル」を押す
3. 相手の場のカードを選ぶ
4. 確認メッセージでOKを押す
5. 攻撃が実行される

カード同士がバトルすると、お互いの攻撃力分だけ体力が減ります。  
体力が0以下になったカードは墓地に送られます。

#### 相手リーダーを直接攻撃する

1. 自分の場のカードを選ぶ
2. 「リーダーを直接攻撃」を押す
3. 確認メッセージでOKを押す
4. 相手リーダーにダメージを与える

相手リーダーのHPを0にできれば勝利です。

### 3. ターンを終了する

行動が終わったら「ターンエンド」ボタンを押します。  
するとCPUのターンになります。

CPUは自動でカードを出したり、攻撃したりします。  
CPUの行動が終わると、また自分のターンになります。

## 勝ち方

相手リーダーのHPを0にすると勝ちです。

## 負ける条件

以下のどちらかになると負けです。

- 自分のリーダーHPが0になる
- 自分のターン開始時に、デッキからカードを引けない

## 操作のコツ

- PPが少ない序盤は、コストの低いカードを場に出しましょう
- 場に出したばかりのカードは、すぐには攻撃できないことがあります
- 攻撃できるカードは、次の自分のターン開始時に行動可能になります
- 相手の場に強いカードがいるときは、先にそのカードを倒すと安全です
- 相手リーダーのHPを削り切れそうなときは、直接攻撃を狙いましょう

## 開発者向けメモ

このゲームは、HTML / CSS / JavaScriptで作成しています。  
現時点ではバックエンドやデータベースは使用していません。

### 主なファイル

- `index.html`：ゲーム画面のHTML
- `style.css`：画面レイアウトと見た目
- `main.js`：ゲームのルール、ターン進行、画面描画、操作処理
- `destyle.css`：ブラウザ標準CSSのリセット

### 実行方法

このリポジトリをダウンロードまたはクローンし、`index.html`をブラウザで開くと遊べます。

ローカル環境で確認する場合は、VS CodeのLive Serverなどを使うと開発しやすいです。
